# adhd-tools

Contributor tools for Crowd-Sourced ADHD, a 3D short film made one small
piece at a time.

Planned:

- `core/`: the checks every submission goes through, plus a CLI
- `blender/`: a Blender add-on to claim a slot, check your work as you go,
  and submit it without touching Git
- `app/`: a desktop app for non Blender work and for donating render time

Nothing is built yet. The design is in [docs/DESIGN.md](docs/DESIGN.md).
